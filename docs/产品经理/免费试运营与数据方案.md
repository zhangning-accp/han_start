# 青禾街免费试运营与数据方案

2026-11-07 更新（v0.4.1）。后续用户决定优先于原注册制初稿：免注册、浏览器匿名身份、SQLite 存储。v0.4 已实现本地可验收版本，未开始公开试运营。

## 试运营节奏

越南、印尼、巴西为试点，全部从新手村同一入口开始。辅助语言与居住国家分别选择，国家允许不提供。免费期按全站开放日期计算，可选 30、60、90 天；开放日期未确定时留空，不显示虚构倒计时。不绑卡、不自动扣费，后续收费另行决定。

开放前完成三国手机访问及母语文案验证；第 30 天看能否开始使用，第 60 天看回访与重复问题，第 90 天评估用户价值和成本。国家间比较同时展示样本量，按招募渠道与观察批次核对，不将小样本差异直接归因为国家。

## 免注册身份与数据存放

用户最终决定：浏览器指纹做 MD5 摘要，以 32 位字符串作为免注册账号编号。输入为浏览器、系统、语言、屏幕、设备能力、时区等有限字段，不枚举字体或读取 Canvas。服务端在内存生成摘要，只持久化 MD5，不保存原始指纹字段。摘要缺失的旧记录暂用原编号，回访时可补充摘要归并。

MD5 用于统计身份，不作为密码。底层每个浏览器仍有独立随机凭证；即使 MD5 相同也不会自动共享私人作品、反馈或删除权限。报表按 MD5 去重估算账号数；可能误合并或拆分，不能当作真实人数。保留有效凭证时沿用首次编号，减少浏览器升级造成的变化。删除仅作用于持有凭证的身份，不能根据 MD5 删除另一个浏览器的数据。

SQLite 文件为 data/han-start.sqlite。JSON 明细自适应无损压缩，压缩封装更小时才保存；索引查询列保持原格式。事务失败回滚，WAL 与 FULL 同步，在线一致性备份及完整性校验。v1 库通过事务升级到压缩 v2，旧 JSON 迁移源保留。压缩不是加密，也不保证数据库文件立即缩小。

浏览器故事进度、未保存草稿和本地手记仍留在浏览器，已保存作品进入数据库；本版没有跨设备找回。

## 国家和其他分类

| 字段 | 规则 |
| --- | --- |
| 国家 | 用户自选 VN、ID、BR、OTHER、UNKNOWN，不由语言或 IP 猜测 |
| 批次国家 | 第一次提供的非未知国家，后续修改不改写回访分组 |
| 活动/反馈国家 | 新事件在客户端记录当时所选国家快照；旧事件缺失该字段时使用服务端资料 |
| 辅助语言 | vi、id、pt-BR、en、zh，与国家独立 |
| 帮助模式 | 零基础、句式帮助、自由输入，来自活动当时状态 |
| 设备 | 手机/电脑粗分类，不建立硬件指纹 |
| 渠道 | 受控 source 推广参数，默认 direct，不收集来源网址全文 |
| 当地时区 | 浏览器 IANA 时区，校验失败留空，不按国家假定单一时区 |

## 指标口径 v2

所有日趋势采用 UTC，自然日未结束的数据会继续变化。后台只展示真实记录，空数据不填演示数字。内部测试访客可由维护命令标记并排除。

| 指标 | 当前实现 |
| --- | --- |
| 新增免注册账户 | 所选日期内首次出现、当前仍存在的非测试 MD5 账户估算数，包含未同意可选统计者；旧记录兼容原编号 |
| 已知/参与统计访客 | 当前身份及当前授权设置概况，不是历史采集覆盖率 |
| DAU | 当日至少一次白名单学习或建造动作的去重匿名身份 |
| WAU/MAU | 截至所选结束日，最近 7/30 天有效交互访客去重 |
| 有效时长 | 页面前台可见、有焦点、交互后 60 秒内的区间累计；后台、空闲和休眠长跳变不计 |
| 日均/中位时长 | 按当天去重访客区间计算；跨 UTC 午夜拆分 |
| 会话 | 同一页面连续使用，30 分钟无交互后再使用生成新会话；多个标签页可能形成多个会话，人数与重叠时长仍去重 |
| 当地时段 | 用设备时区拆分星期 × 小时，展示有效分钟和访客数；未知时区另列 |
| D1/D7/D30 | 首次同意统计为 D0，只纳入持续授权且对应完整 UTC 日已结束者；指定返回日有有效交互为回访 |
| 24 小时激活 | 首次授权后 24 小时内真实完成新手村且保存作品；窗口未满单列观察中 |
| 体验步骤 | 各步骤独立访客数，不把不同批次人数直接包装为转化率 |
| 反馈 | 按提交时间、国家、语言等筛选，保留原文和处理历史 |

仅打开网页、切换语言、查看后台不计产品 DAU。查看和阅读可能产生有效使用时间而没有学习动作，不能用时长代替学习效果。关闭统计者缺少行为数据，不能算作没有活动或流失；中途退出的访客永久排除该次回访观察，重新同意不会补造退出期间数据。

所有比例显示分子、分母和未成熟人数。国家活动行可能包含同一访客，不相加得到全站总数；回访始终按首次国家归组，即使后续换国仍可认定返回。设备与难度筛选只作用于行为，新增访客不会按这两项分配。

## 功能与个人维度

后台分开呈现“瞬时操作”与“功能区”。打招呼、练习提交、保存、查看帮助、语言/难度切换、跳过、AI 开关、共建提交、作品参观等计次数和独立账号；新手村、夜市主线、独立复测/问路、建造、共建浏览、手记、访客设置/反馈分别累计有效时长。

按功能区显示总时长、人均、中位时长、进入次数；按国家显示同样的指标；个人页可筛选一个 MD5，再看各功能及当地星期/小时分布。CSV 导出全部个人 × 功能区及当地时段明细，后台个人列表最多先展示 100 个并支持编号定位。

切换功能时结算原功能区时间，跨午夜/小时拆分。同账号多浏览器或标签页重叠区间只计一次，按最早开始的区间归属；这也意味着指纹误合并会影响时长。旧记录没有功能字段时保留为未归属，不推测补填。功能筛选只影响行为，账号新增归属不按功能重算。

练习记录题目、当时帮助设置、尝试次数和通过/重试；不上传完整回答。通过只代表当前游戏规则通过，不代表语言能力。最后场景记录只提示可能中断点，不确定退出原因。自动展开译文不再计为主动请求帮助；历史帮助记录不能倒推是否主动。

## 需求验证方法

| 待验证问题 | 行为证据 | 必须结合的解释 |
| --- | --- | --- |
| 是否有人愿意开始学 | 新账户、开始新手村、实际学习动作 | 需要结合招募来源和未参与统计比例 |
| 能否顺利学下去 | 新手村完成、练习重试、帮助、保存失败 | 低完成可能是操作或翻译问题，不直接等于无需求 |
| 是否接受游戏式学习 | 是否进入下一章、建造/练习投入、跳过比例 | 时长长可能是困难；反馈原文用于解释 |
| 什么功能值得投入 | 功能独立账户、重复使用、时长、不同国家比较 | 同时看人数与次数，避免重度个体误导 |
| 是否持续需要 | D1/D7/D30、重访、后续章节 | 等待成熟窗口；不能提前把观察中记为流失 |

试运营每周从上述证据提出下一项小改动，不宣称凭一次点击就证实需求。当前已有开放反馈，尚未加入结构化“喜欢这种方式吗/为什么离开”问卷，必要时应结合自愿访谈。

## 数据采集与反馈

首次以对应辅助语言说明用途，可选行为统计默认关闭。必要身份、用户主动保存的作品和提交的反馈不依赖可选分析开关。开启后按动作白名单记录，不上传完整输入、按键内容、录音或屏幕录像。

时长约每 15 秒上报一个区间，单段最多 30 秒；同一访客重叠区间取并集，事件 ID 防重复，断网队列限制数量及有效时间。突然关闭可能丢少量未送达区间，不虚构剩余时长。客户端统计可被篡改，本版不用于资金结算或严格真人验证。

反馈分类：操作不明白、中文太难、翻译问题、程序故障、功能建议、其他。用户以熟悉的语言填写，服务器确认收到后才显示成功，重试相同 ID 不重复创建。后台支持待查看、已分类、处理中、已解决、暂不处理，保存优先级、时间及处理备注。备注会展示给提交者，运营人员应使用其能理解的语言。其他学习者无法查看此反馈。

## 后台与保留规则

维护者使用独立管理口令访问 /admin.html；普通访客不能读取全站统计、其他反馈或 CSV。筛选支持 UTC 日期、国家、辅助语言、帮助模式、设备、来源、功能区和个人账号 MD5。CSV 与当前已加载筛选一致，标明指标口径和时间范围。试运营配置与反馈处理均需管理权限。

行为明细保留 120 天，启动和每小时执行过期清理。访客资料、作品及反馈当前保留至本人删除或后续试运营清理决定，不擅自删除作品。个人导出与删除覆盖当前库，已删除访客从历史动态报表移除。历史备份与迁移源文件不自动改写，需要单独管理保留期限；恢复旧备份前重新应用删除请求。不得把备份放入公开静态目录。

目前提供手动在线备份命令，尚未配置定时备份和异地副本。正式试用前确定每日备份负责人/自动任务、保留期限、恢复演练与磁盘空间告警。SQLite 未加密，主机和备份访问权限必须由部署环境保护。
