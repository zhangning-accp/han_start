## v0.4.3 手写输入

新手村的问候、饮品、邀请及完成页新增可展开的“手写试一试”；夜市答题和独立练习默认提供单字手写输入。用手指、触控笔或鼠标书写，点识别后从候选字中确认，逐字组成回复；支持撤销一笔、清空笔迹、删除最后一个字及加入标点。仍可选择键盘，原有词块帮助保留。确认候选字不会提交答案，也不会推进剧情。

识别在浏览器内运行，采用笔画形状模板匹配，按字形、笔画顺序与笔画数量生成最多 8 个候选字，不根据当前任务答案强行匹配。适用于较清晰、尽量遵循笔顺的单字；不保证潦草字、连笔、笔顺差异大时的识别率，不做笔顺教学、书写评分或语言水平判定。新手村练习文字与未确认笔迹为临时内容，离开或刷新会清空；正常确认后的答题文字只有点击发送才进入现有答题流程。

字库含 9565 个汉字，取自 hanzi-writer-data 2.0.1（来源为 Make Me a Hanzi 图形数据），仅保留笔画中线坐标并翻转 Y 轴，未引入其 JavaScript 库。原始包 SHA-512 校验通过。数据按 Arphic Public License 提供，修改声明内嵌在 medians.json；许可、来源和修改说明位于 public/handwriting-data/。首次使用从本站加载，gzip 约 2.42 MB，随后在当前页面内复用；不需要访问者安装中文键盘或提供 AI API 密钥。笔迹不上传、不持久化；新增功能次数统计沿用既有用户同意机制，只记录展开、识别、选字、撤销、清空、加载失败，不记录笔迹或所选文字。

TDD：先验证识别/撤销/候选确认、过期异步结果、入口、触控取消、静态资源及统计的预期失败，再实现。全部 68 项测试通过，包括完整字库上的手工坐标样例“十、人、口、水”。实际网页用鼠标绘制“十”并确认候选字，验证新手练习输出、夜市回复填入、删除、标点及键盘切换。尚未验证手机与触控笔实机、多用户字迹识别率或教师验收，不把少量样例通过当成通用识别准确率。

## 启动

环境：Node.js 24.14 或以上（本机验证版本 24.19）。使用 maxmind 读取随项目提供的 DB-IP 免费国家库。首次运行需先安装锁定的依赖；每次查询在本地完成，不调用付费 IP 服务。

```powershell
cd D:\programming_projects\han_start
npm ci --omit=dev --ignore-scripts
npm start
```

浏览器打开 http://localhost:3210 。停止服务按 Ctrl+C。请保持同一地址和浏览器以恢复个人进度。

`localhost:3210` 与 `127.0.0.1:3210` 是两个浏览器身份，可用于本地演示投稿者和新体验者；它们共享同一份本机公共世界。页面、源码及固定教学内容都由本机提供，无外部字体或分析服务。

## DeepSeek 配置

根目录已提供 `.env` 配置位置（不会在升级时覆盖），只需在本机编辑 `DEEPSEEK_API_KEY=` 后面的值，再重启服务。不要把密钥发到聊天、截图或代码仓库。`.env` 和 `data/` 已在忽略列表中；本目录尚未初始化 Git。

```dotenv
DEEPSEEK_API_KEY=在本机填写
DEEPSEEK_MODEL=deepseek-flash
AI_DAILY_LIMIT=30
AI_TIMEOUT_MS=8000
PORT=3210
```

模型可替换为账号实际可用的模型。实现依据 [DeepSeek 官方 Chat Completions 文档](https://api-docs.deepseek.com/api/create-chat-completion/)：服务端调用 `/chat/completions`，禁用思考模式，JSON 输出，最多 220 输出 token。尚未进行真实账户联调或计费验证；以本机实际配置为准。

配置密钥不会自动发送输入。学习者须在任务中主动勾选 DeepSeek 建议；只发送当前场景、教学目标、参考表达及当前回答，不发送昵称、身份、历史聊天或投稿。开关不持久化，刷新后关闭。AI 只提供建议，不能改判、授权或改变世界。无配置、超时、格式错误、上游故障、每日额度耗尽均回退到规则演示；失败不自动重试。调用计数跨重启保存，按 UTC 日期重置，每次最多 8 秒（可配置）。调用上限是次数限制，不是金额预算。服务端仅记录结果及 token 用量，不记录作答原文。

## 体验路径

1. 第一章：选择语言、昵称和起步难度 → 点“你好” → 选茶或水 → 放置桌子和植物并保存 → 点“请坐”“谢谢”邀请邻居。第二章：茶铺介绍自己 → 看公告确认安排 → 向陈安申请东侧摊位 → 向阿禾借桌子并商量六点来取 → 亲手布置并保存摊台、招牌和装饰 → 邀请朋友七点来，夜市亮灯。
2. 首次选择越南语、印尼语、巴西葡萄牙语、英语或中文。零基础模式可点词组句，有基础模式提供句式填空，挑战模式自由输入。页面上方“学习帮助与章节”可切换难度、跳过或返回引导；已有夜市进度与作品保留。点击可选帮助查看句框、拼音或相应辅助语言。规则支持配置内常见变体，无法覆盖任意自然表达；有争议可提交仅维护者可见的反馈。
3. 夜市结束后在「我的手记」参加三个新情境首次复测；完成夜市 24 小时后解锁另一个延迟复测。首次检查没有提示，作答后显示反馈。不伪造延迟测试或学习数据。
4. 在「一起共建」保存草稿、选择署名、阅读公开说明后提交；投稿不自动发布。
5. 本地维护者审核后发布，地图出现指路牌，可点击体验洗手间问路；另一身份能看到新增设施、署名和年鉴。玩家作品可按原布局共享，其他身份可参观并提交针对招牌的纠错；不会把任意创意自动转换为教学内容。

## 作品审核与回滚

SQLite 事务允许维护命令与本机服务并行执行；修改前请备份。网站管理员可登录 `/admin.html#moderation`，在“作品审核”中预览投稿，填写署名和意见，选择“通过并发布”“要求修改”或“拒绝”。待处理列表不受统计日期筛选影响，已处理、撤回记录单独收起。审核接口沿用管理员会话和请求来源校验，普通访客无权访问。通过并发布在同一事务内完成原有审核、批准、发布步骤；状态、审核记录或公开版本已变化时拒绝旧页面操作，失败不留下部分审核结果。用户提交后自动展开状态区，在“我的投稿”查看意见或撤回。

维护者仍可通过本机命令审核和回滚：

```powershell
npm run moderate -- list
npm run moderate -- review 投稿ID "进入审核" "维护者姓名"
npm run moderate -- revise 投稿ID "请补充真实场景" "维护者姓名"
# 提交者在页面修改并重新提交后，再 review。
npm run moderate -- approve 投稿ID "符合指路牌与问路教学目标" "维护者姓名"
npm run moderate -- publish 投稿ID "新增入口指路牌及问路事件" "维护者姓名"
```

建造投稿按实际布局审查，纠错投稿按指定招牌审查；普通场景建议仅批准适合预写问路设施的内容。其他建议可以 `revise` 或 `reject`，需提供理由；撤回、拒绝、需修改记录可 `archive`。发布必须先 review，再 approve，再 publish，重复发布会拒绝。

```powershell
npm run moderate -- rollback 1 "恢复最初世界" "维护者姓名"
```

回滚创建新版本并保留年鉴，不改变个人故事进度。`export` 命令输出维护者本机数据（含投稿身份），不要当作可公开文件分享。

## 数据与删除

- 无需邮箱或密码。浏览器、系统、语言、屏幕、设备能力与时区字段传到本站后，在内存中规范化并生成 MD5；只保存 32 位摘要作为免注册账户编号，不保存原始指纹字段。不使用 Canvas 或字体枚举。匹配摘要的浏览器身份在报表归并；私人作品与反馈仍按独立 HttpOnly 凭证隔离，MD5 不能用于登录或找回。浏览器特征相同可能误合并，特征变化且失去原凭证可能拆分。
- 国家、语言、统计设置、行为明细、反馈及其处理记录、作品、投稿、审核快照和 AI 用量保存在 `data/han-start.sqlite`。访客、活动、反馈、作品和投稿分别建表，使用外键、索引、事务、WAL 和 FULL 同步。较大 JSON 记录以 Deflate + Base64 封装压缩，只有确实缩小时才采用；时间、国家、归属等查询列保持可索引。压缩不是加密，数据库文件页数也不保证立即缩小。
- **本版故事进度、未保存的建造草稿及本地学习手记仍保存在浏览器** `han-start-v1`；已点击保存的作品在 SQLite 中。没有跨设备恢复入口，不能仅靠数据库恢复丢失的浏览器凭证。
- 默认关闭可选行为分析。开启后只上报白名单动作、练习结果与帮助设置、经过校验的功能区时间区间和分类信息；不上传键盘输入过程、录音或完整作答。时长为估算值，空闲超过 60 秒、隐藏或失去焦点时暂停。
- 行为明细保留 120 天，启动时及运行中每小时清理过期记录。关闭统计后停止新采集；个人导出包含当前身份的资料、作品、反馈和行为记录。删除通过服务端确认后移除当前库对应数据；不影响其他访客。历史备份和原迁移文件不自动改写，需要按备份保留策略单独管理，恢复旧备份前须重新应用删除记录。
- 首次启动自动迁移原 `data/world.json`，成功后不再向 JSON 写入，原文件完整保留。已有作品修订、公共世界版本及审核历史保留，缺少字段的旧事件不会被补造为新试运营活跃数据。

## 运营后台与备份

学习者无需注册；维护者使用独立管理口令。首次在项目目录运行下面的初始化命令，把终端显示的口令保存在密码管理器，然后访问 http://localhost:3210/admin.html 。口令只在初始化/重置时显示，数据库存加盐哈希；未初始化时后台不开放数据。

```powershell
npm run admin -- init
# 忘记口令时重置，并撤销旧管理会话
npm run admin -- reset
# 从个人导出文件取得访客 ID，排除内部测试身份
npm run admin -- mark-test 访客ID
# 服务运行中也可执行一致性备份，文件保存在 data/backups/
npm run backup
```

## 尚未实现与运行限制

应用仅监听回环地址，通过服务器 Nginx 提供公网 HTTPS。SQLite 与匿名凭证已经实现，海外连通性、负载和灾难恢复验收仍未完成。查询目前在内存计算，适合小批次试用验证，正式扩大规模前需测量数据量与查询耗时。

固定规则可能误拒或误收超出回归集合的表达；目前 AI 不辅助改判。尚无专业中文教师审核、真实成人研究、真实语音/听说测量、AI 金额核算、自由剧情生成或三种试点语言的母语校对。手机浏览器实机测试、真实 DeepSeek 调用、24 小时后的延迟复测和七日观察仍待实际使用验证。

历次验收留下了明确标注「本地验收测试」或 QA 的共建发布、作品、纠错、回滚及测试身份进度，不能作为真实用户需求或学习效果证据。
